# Modern Hesap Makinesi

Bu proje, Python ve `tkinter` kütüphanesi kullanılarak oluşturulmuş modern bir masaüstü hesap makinesi uygulamasıdır. Hem temel aritmetik işlemleri destekler hem de şık ve kullanıcı dostu bir arayüze sahiptir.

## Uygulama Görseli

Aşağıda uygulamanın arayüzünü gösteren bir ekran görüntüsü bulunmaktadır:

![Hesap Makinesi Arayüzü](calculator_screenshot.png)

## Özellikler

- **Dört Temel İşlem:** Toplama, çıkarma, çarpma ve bölme.
- **Modern Tasarım:** Koyu tema ve duyarlı düğmelerle estetik bir görünüm.
- **Kullanıcı Dostu Arayüz:** Geniş giriş alanı ve kolay tıklanabilir düğmeler.
- **Hata Yönetimi:** Geçersiz matematiksel işlemler için hata mesajları gösterir.

## Gereksinimler

Uygulamayı çalıştırmak için sisteminizde Python ve `tkinter` kütüphanesinin kurulu olması gerekmektedir. `tkinter`, genellikle Python standart kütüphanesi ile birlikte gelir.

- Python 3.x
- Tkinter

## Nasıl Çalıştırılır?

1.  Projeyi bilgisayarınıza klonlayın veya indirin.
2.  Terminal veya komut istemcisini açın.
3.  Proje dizinine gidin.
4.  Aşağıdaki komutu çalıştırarak uygulamayı başlatın:

    ```bash
    python calculator.py
    ```

Uygulama penceresi açılacak ve hesap makinesini kullanmaya başlayabilirsiniz.
